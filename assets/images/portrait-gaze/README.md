# Cursor-following portrait set

Nine 960 × 960 frames power the professional hero portrait:

- `walid-gaze-center.jpg` — front-facing navy quarter-zip portrait, used as the neutral state.
- `walid-gaze-up-left.jpg`, `walid-gaze-up.jpg`, `walid-gaze-up-right.jpg`.
- `walid-gaze-left.jpg`, `walid-gaze-right.jpg`.
- `walid-gaze-down-left.jpg`, `walid-gaze-down.jpg`, `walid-gaze-down-right.jpg`.

The eight directional frames were generated from the selected casual center
portrait with the built-in image generation workflow. Each prompt used the
`identity-preserve` edit mode and changed only the restrained head angle and eye
gaze while keeping the crop, navy quarter-zip, glasses, hair, facial hair,
lighting, background, and expression consistent. The delivered JPEGs are
resized to 960 × 960 at quality 84.
