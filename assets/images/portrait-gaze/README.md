# Cursor-following portrait set

Nine 960 × 960 frames power the professional hero portrait:

- `walid-warm-gaze-center.jpg` — front-facing navy quarter-zip portrait, used as the neutral state.
- `walid-warm-gaze-up-left.jpg`, `walid-warm-gaze-up.jpg`, `walid-warm-gaze-up-right.jpg`.
- `walid-warm-gaze-left.jpg`, `walid-warm-gaze-right.jpg`.
- `walid-warm-gaze-down-left.jpg`, `walid-warm-gaze-down.jpg`, `walid-warm-gaze-down-right.jpg`.

The eight directional frames were generated from the selected warm-paper center
portrait with the built-in image generation workflow. Each prompt used the
`identity-preserve` edit mode and changed only the restrained head angle and eye
gaze while keeping the crop, navy quarter-zip, glasses, hair, facial hair,
warm ivory background, lighting, color treatment, and expression consistent.
The delivered JPEGs are resized to 960 × 960 at quality 84.
