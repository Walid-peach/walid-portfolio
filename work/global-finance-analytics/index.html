Case study 03 / Finance analytics / 2023—2024

One reporting model across borders.

Finance data for 18 countries and 12 currencies unified through controlled exchange rates, country-level row security, and shared group reporting.

18Countries governed
12Currencies aligned
RLSCountry-level access

Context

Group reporting needs a consistent model across local entities without ignoring country-level access boundaries or the currency conversions behind consolidated figures.

Delivery

The system combines PySpark, dbt, Delta Lake, Power BI, and Kyriba exchange rates. Transformations establish shared finance models, while country-level row security controls which data each audience can access.

Engineering decisions

  • Centralize exchange-rate handling through controlled Kyriba inputs.
  • Use shared transformation models for consistent group reporting.
  • Apply row-level security at country level.
  • Keep reporting semantics aligned with the governed data foundation.

Outcome

The resulting analytics foundation supports consistent reporting across 18 countries and 12 currencies while preserving country-level access controls.
